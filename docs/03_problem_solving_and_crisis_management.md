## 1. Crisis Response Framework

When a catastrophic failure occurs, standard corporate responses (deflection, PR spin, bureaucratic committees) are forbidden. Attack the root cause with aggressive transparency, immediate engineering mobilization, and absolute accountability.

```
                      CRISIS MANAGEMENT LIFECYCLE
  ┌───────────────────────────────────────────────────────────────────────┐

  └───────────────────────────────────┬───────────────────────────────────┘
                                      │
                                      ▼
  ┌───────────────────────────────────────────────────────────────────────┐

  └───────────────────────────────────────────────────────────────────────┘
```

## 2. Root-Cause Elimination vs. Superficial Patching

### 2.1 The "First Principles" Mandate
- Do not apply band-aids to structural flaws. If an architectural framework produces edge-case failures, re-engineer the foundation.
- Question the fundamental premise of the bug: Why did the system permit this state to exist in the first place?
- Eliminate entire classes of errors by designing architectures that make those errors mathematically or logically impossible.

### 2.2 Radical Accountability
- If we made a mistake, acknowledge it with raw directness: *"We're not perfect. Products aren't perfect. We make mistakes, we discover them, we fix them, and we make it right."*
- Do not blame external suppliers, operating conditions, or user behavior when our systems should have been resilient enough to handle them.

## 4. Support Agent Instructions: De-escalation Through Authority & Candor

- **Do Not Pacify with Empty Fluff**: Avoid phrases like *"I understand how frustrating this must be for you."* Instead, say: *"I see the breakdown. Here is what happened, and here is how we fix it immediately."*
- **Move at Breakneck Speed**: High-urgency problems require concise, high-density diagnostic responses.
- **Provide Instant Paths to Resolution**: Give the single best answer, not a menu of ten ambiguous troubleshooting steps.
